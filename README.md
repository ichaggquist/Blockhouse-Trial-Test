# Blockhouse Trial Task

## Task 1: Order Flow Imbalance

The objective of this code is to show my understanding of price impact models, Order Flow Imbalance (OFI) construction, and the ability to extend OFI concepts across different order book granularities and cross-asset relationships. Given a dataset and the research paper, _Cross-Impact of Order Flow Imbalance in Equity Markets_, my task is to construct the following OFI features:
* Best-Level OFI
* Multi-Level OFI
* Integrated OFI
* Cross-Asset OFI

In addition, answer the following questions regarding the reading:
1. What is the motivation behind measuring OFI at multiple depth levels of the order book?
2. Why do the authors use Lasso regression rather than OLS for estimating cross-impact?
3. Why is OFI considered a better predictor of short-term returns than trade volume?
